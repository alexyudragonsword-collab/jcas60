## 2026-11-27 · 预期：接收侧对泄漏置零做成算法（feat/milestone-1-leak-nulling；跑之前写）

ROADMAP 里程碑 1 剩下的第 2 件，用户点的。示例 03 加 §4，仍是 1 发 8 收、每路 40 dB 隔离、目标在 20°。上一步只量了“泄漏恰好落在零点”的上界；这一步让合成器自己把零点放过去。

- **做法**：泄漏只有一个发射波形，在 N 条链上就是一个复向量 v（秩 1），不管它的相位是什么样——不需要那个缺着的耦合模型，从数据里估。两种合成权：
  - （投影）v 取各链零多普勒、泄漏时延那一格的包间平均；权 = 把波束方向的导向矢量里沿 v 的分量投掉。
  - （自适应，MVDR）协方差取自各链图上不含目标与零多普勒脊的噪底格；权 = R⁻¹ a。不用单独估 v。
- **闭式**（ρ² = 泄漏在波束方向剩下的份额，N·pn / σ² 取上一步的数）：常规 35.65 − 10·log10(σ² + N·ρ²·pn)；投影 34.00 + 10·log10(1 − ρ²)；MVDR 34.00 + 10·log10(1 − ρ²·N·pn / (σ² + N·pn))。
- **预期**（ρ² = 1 / 0.5 / 0.125 / 0）：
  - Z1 常规 26.09 / 28.45 / 31.83 / 34.00 dB。
  - Z2 投影 盲 / 30.99 / 33.42 / 34.00 dB：ρ² = 0.125 时比常规多 1.6 dB，0.5 时多 2.5 dB；泄漏正在波束方向时这个方向看不见。
  - Z3 MVDR 26.09 / 31.64 / 33.52 / 34.00 dB：处处不低于另两种；ρ² = 1 时与常规相同（零点放不出来）。
  - Z4 两条路各差 < 0.5 dB。估出来的 v 与真值的夹角：投掉之后泄漏剩 < −40 dB。
  - Z5 **不靠模型的一句话**：N 个正交波束上 ρ² 之和恒为 1（Parseval），所以投影之后泄漏的代价是“一个波束的份额”——各波束线性增益平均掉 1/N（−0.58 dB），不管 v 长什么样。用随机的 v 数值核一遍。

## 2026-11-27 · 预期：里程碑 1 第二步——接收阵列（feat/milestone-1-rx-array；跑之前写）

- **三种花法**（N = 8，5 m，闭式）：（甲）1 发 N 收；（乙）N 发扫、1 收（示例 02）；（丙）N 发扫、N 收。
  - X1（甲）：SNR = 单天线 + 10·log10(N) = +9.03 dB，**两种法规读法都拿得到**（接收增益不占 EIRP）：通信读法 L-CEF 39.77 / TRN 52.78 dB，雷达读法 37.77 / 50.78 dB。一帧看全部方向，空口时间 ×1。
  - X2（丙）：通信 57.77 / 70.78 dB，雷达 37.77 / 50.78 dB（发射阵列在雷达读法下仍旧白搭）；空口 ×8。

- **第二条路**（N = 8，目标在 20°）：
  - X4 8 路各自仿真、数字合成：SNR 比闭式（单路格点 SNR + 9.03 dB，两程的单元方向图 −1.08 dB）差 < 0.3 dB。
