# 接收阵列（里程碑 1 第二步）

> 当前真相。数字在 `python examples/03_receive_array.py`（约 55 s；写作“示例 03 §n”），代码在 `src/jcas60/rxarray.py`，取舍在 `jcas60.rx_array`（单元、间距、视场沿用 `jcas60.array`）。对照表的行没有换。发射阵列那一步在 `transmit-array.md`。

## 结论

1. **接收阵列的增益不受法规上限管，两种读法都拿得到**（§1）。1 根发射天线、N 条接收链、数字合成波束：SNR = 单天线 + 10·log10(N)。N = 8：通信读法 L-CEF 30.74 → 39.77 dB、TRN 场 43.75 → 52.78 dB；雷达读法 28.74 → 37.77 dB、41.75 → 50.78 dB。发射阵列在雷达读法下一分不给（示例 02），接收阵列给足 9 dB。
2. **同样的空口时间下，“发射扫”买到的就是“只收”买到的，还赔上多普勒轴**（§1）。N 个发射单元扫 N 个方向、每个方向只分到 1/N 的包：N = 2、4 时 SNR 与只收阵列逐位相同，N = 8 低 0.06 dB（那是到上限的回退），N = 16 低 6.08 dB（EIRP 封顶了）；速度分辨粗 N 倍（N = 8：0.39 → 3.10 m/s）。雷达读法下它比只收阵列低 20·log10(N)（N = 8：18 dB）。发射扫剩下的好处只有一条：接收链只要一条，不是 N 条。
3. **两头都用**（N 发扫、N 收）：通信读法 N = 8 是 57.77 / 70.78 dB，空口时间 ×8；雷达读法与只收相同（37.77 / 50.78 dB），发射那一半白搭。
4. **一帧就能定方向，到 CRLB**（§2，N = 8，目标在 20°）。8 路各自仿真、合成：单路 28.93 dB（闭式 28.79），合成 37.82 dB（闭式 37.82），增益 8.89 dB（闭式 9.03）。方向取合成后那一格最大处：32 帧的 rms 误差 0.083°，CRLB 0.077°，无偏（均值 +0.014°）；波束宽 13.6°，即波束的 1/160。示例 02 的“扫 8 个方向”在这里是一帧。
5. **泄漏进每一条接收链：压缩不因阵列而放宽，相噪看泄漏在合成里的相位**（§3，1 发 8 收，每路 40 dB 隔离）。
   - 每条链各自压缩，需要的隔离就是单天线的 43.24 dB（最紧的仍是压缩）。
   - 合成之后回波按幅度相加（×N²），各路的热噪声与 ADC 噪声按功率相加（×N）；泄漏上的相噪残余各路相同（同一个本振、同一个波形），跟着泄漏过合成器。泄漏在各单元上的相位没有模型，用“像从哪个方向来的波”参数化：

     | 泄漏过合成器 | 剩下的份额 | SNR（闭式 / 仿真） | 比单路带泄漏的 22.80 dB 多 |
     |---|---:|---:|---:|
     | 正在波束方向 | 1 | 26.09 / 25.86 dB | 3.3 dB |
     | 主瓣裙上，剩 1/N | 0.125 | 31.83 / 31.55 dB | 9.0 dB |
     | 第一个零点 | 0 | 34.00 / 33.90 dB | 11.2 dB |
     | 不带泄漏 | — | 37.82 / 37.90 dB | — |

   - 泄漏落在零点时比 10·log10(N) 还多 2.2 dB：相噪残余被合成器整个抵掉，只剩各路自己的噪声。这是只有数字合成才有的手段——**对泄漏的方向置零**（接收侧的波束置零）在这套模型里值 8 dB（26.1 → 34.0 dB），没有做成一个算法，只量了它的上下界。

## 前提

- 均匀直线阵、间距 λ/2、单元方向图 cos（两程按 cos⁴：20° 处 −1.08 dB），几何与阵因子是 arraytx 的（vendored）。**单元天线没有建模**：10 dBi 的单元增益与 λ/2 的间距不自洽（同 `transmit-array.md`）。
- 每条接收链是表里那台接收机与 ADC 原样一份（3.52 GS/s 复采样、ENOB 9.09），N 条就是 N 份：数据量与功耗 ×N，这一项没有折成数。
- 各链共用一个本振（仿真器里：同一个随机种子出相噪，热噪声另起一个流）。不共用时泄漏上的相噪残余各路不相干，三种情形并成“功率相加”那一种。
- 链间的增益与相位失配、互耦、校准都没有；测角到 CRLB 是在这个前提下。
- 目标是单个点目标；同一格里两个方向的目标分不分得开没有量。
