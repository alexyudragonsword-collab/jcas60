# 发射阵列（里程碑 1 第一步）

> 当前真相。数字在 `python examples/02_transmit_array.py`（约 45 s；写作“示例 02 §n”），代码在 `src/jcas60/arrays.py`，取舍在 `jcas60.array`。对照表（`comparison-table.md`）的行没有换：这里是把表的问题在“N 个发射单元”这个自变量上再问一遍。

## 结论

1. **8 个单元正好顶到通信限值，再多没有用**（§1）。每个单元一个 12 dBm 的 PA、10 dBi 的单元，满功率 EIRP 是 22 + 20·log10(N) dBm：N = 8 是 40.06 dBm，回退 0.06 dB 就在 40 dBm 上。B 行按闭式 L-CEF 30.74 → 48.74 dB、TRN 场 43.75 → 61.75 dB（5 m，接收仍一根天线）。N = 16 EIRP 不涨，每个 PA 回退 6.08 dB。
2. **按雷达读法，阵列买不到 SNR**（§1）。上限是峰值 20 dBm，单天线已经要回退 2 dB；N 个单元 EIRP 仍是 20 dBm，SNR 不动（28.74 / 41.75 dB），每个 PA 回退 2 + 20·log10(N) dB（N = 8：20.06 dB）。两种读法的差从 2 dB 变成 20 dB——“通信设备顺带感知适用哪一款”这个没有定论的问题，有了阵列之后值 18 dB。
3. **+18 dB 是用方向换的**（§2）。N = 8 的波束宽 12.79°（arraytx 的阵因子；连续口径的闭式 12.69°），盖住 ±60° 要 8 个方向（相邻波束在半功率处相交，按 sin θ 等间隔）。每个方向发一帧感知包，每秒仍扫 30 遍：空口时间 L-CEF 1.16 % → 9.30 %，TRN 场 4.51 % → 36.11 %；或者空口时间不变，每个方向每秒只看 3.75 次。N = 16：18.6 % / 72.2 %。视场边上单元方向图（cos）再丢 6.02 dB（单程）。
4. **波束偏斜不成问题**（§3）。相位扫描、2.2 GHz 占用带宽、扫到 60°，带边偏 1.80°；N = 16（波束 6.36°）时相关峰丢 0.050 dB，30° 处 0.017 dB，真时延为零。两条路四位小数相同。信道绑定（带宽 ×2、×4）时按平方涨，到时再看。
5. **单站行：泄漏把阵列的增益拿回去大半**（§5；跑之前没有预期到）。N 个 PA 都在接收天线旁边。每个单元按单天线的隔离（找到的最好的 40 dB）漏进来，相位扫描下 N 路泄漏是同一个波形，按相量相加——相位本库没有模型，给两个界：
   - 全部同相（就是表里原来的式子 EIRP − G_t − 隔离）：N = 8、通信限值下泄漏 −10.0 dBm，隔离要 61.24 dB（缺 21.24 dB），SNR 剩 25.19 dB——比单天线的 23.88 dB 只多 **1.3 dB**。
   - 功率相加：泄漏 −19.0 dBm，隔离要 52.21 dB（缺 12.21 dB），SNR 剩 33.92 dB，多 **10.0 dB**。
   - 不带泄漏是 47.87 dB（多 18.0 dB）。最紧的一条在每个 N、每种读法下都是带内压缩。
   - 雷达读法下反过来：PA 回退之后总传导功率随 N 降，功率相加时 N ≥ 2 起 40 dB 隔离就够了（N = 8 余 7.8 dB），同相时与单天线相同（缺 1.24 dB）。
   - 两条路（N = 8、通信限值，限幅器 + 相噪 + ADC 全开）：功率相加 33.92 对 33.77 dB，同相 25.19 对 25.17 dB。

## 前提（每条都是 `jcas60.array` 的取舍，换了会动什么写在条目的 note 里）

- 均匀直线阵、间距 λ/2、单元方向图 cos、相位扫描；几何、阵因子、逐单元驱动与远场合成是 arraytx 的 `geometry` / `beam`（经 mmw60_trx vendor，两个文件只依赖 numpy）。mmw60_trx 自己的阵列链路（`arraylink.py`、`frontend/array60.py`）站在 `Frontend60` 与 wifitrx 上，没有拷——里程碑 0 的边界仍成立。
- **单元天线没有建模**：10 dBi 的单元增益（表里发射天线的那个数）与 λ/2 的间距不自洽（10 dBi 的口径比 λ/2 大）。EIRP 的 20·log10(N) 不受影响，视场边上的损失与栅瓣会。
- **接收仍是一根天线**。接收也用阵列时 SNR 再 +10·log10(N)，泄漏怎么进 N 路接收又是另一件事，没有算。
- **泄漏的相位没有模型**：两个界之间差 10·log10(N)。相位随波束指向变，所以泄漏的电平每换一个方向都不一样；每个单元的隔离也随它离接收天线的远近变。要收窄得有耦合的几何（或测量值）。
- 闭式的波束宽度是连续口径的（0.886·λ/(N·d)）：阵列自己的在小 N 时更宽（N = 2：59.9° 对 50.8°，N = 4：26.3° 对 25.4°，N ≥ 8 差 < 1 %）。方向数两种算法都向上取整到 N。
- 感知的“扫”是每个方向一帧感知包，不是 SSW 帧；扇区扫描帧的时长（`dmg.ssw_frame`、`edmg.short_ssw`）这一步没有用。

| 波束宽度（N = 8） | 连续口径 12.69° | arraytx 的阵因子 12.79° | 0.8 % |
| 方向数（N = 8） | 7.82 | 阵因子自己的宽度 7.77；摆出来 8 个，相邻两个在中点各 −3.0 dB | — |
| 波束偏斜（N = 16，60°） | 升余弦谱按 `beam_response` 加权 0.0499 dB | 感知场逐单元驱动、远场合成、相关 0.0499 dB | < 0.001 dB |
